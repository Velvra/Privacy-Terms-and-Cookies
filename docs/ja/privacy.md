# <i class="fa-solid fa-lock" style="color: var(--velvra-primary); margin-right: 8px;"></i> プライバシーポリシー

**発効日:** 2026年4月15日  
**最終更新日:** 2026年4月15日

このプライバシーポリシーは、Velvra（Creative Frameworkが運営）が収集するデータ、使用方法、およびユーザーの権利について説明しています。DiscordサーバーにVelvraを追加する、またはボットとやり取りすることにより、以下の慣行に同意したものとみなされます。

### 1. 収集するデータ

Velvraの機能が動作するために必要な最小限のデータのみを収集します。すべてのデータは、Discord APIまたはボットコマンドからの直接のやり取りからのみ取得されます。

#### 1.1 ユーザーデータ
| データポイント | 目的 | 保存期間 |
|---|---|---|
| **DiscordユーザーID** | プロフィール、XP、経済、設定をリンクするため | 削除の要求があるまで |
| **XPおよびレベル進行** | グローバルなレベリングとクエストシステムを提供 | 永続的 |
| **経済残高および取引履歴** | コイン、デイリー報酬、ピアツーピアの送金追跡 | 永続的 |
| **プロフィールタイトルおよび評判** | 公開プロフィールのカスタマイズ | 永続的 |
| **バッジ** | 獲得または割り当てられた達成状況の追跡 | 永続的 |
| **通知設定** | DM通知（レベルアップなど）の選択を尊重 | 永続的 |
| **クエストの進行とアクティビティ追跡** | デイリークエスト（メッセージ数、コマンド使用など） | 毎日リセット（合計値は永続） |
| **プレミアムステータスおよびブラックリスト** | 機能の制限と悪用の防止 | 永続的 |

#### 1.2 サーバー（Guild）データ
| データポイント | 目的 | 保存期間 |
|---|---|---|
| **サーバーIDおよびオーナーID** | サーバーとそのオーナーの構成の特定 | ボットが削除されるまで |
| **サーバー名、アイコン、およびメンバー数** | ダッシュボードとログの表示用 | イベント時に更新、削除時に消去 |
| **言語および方言のプレファレンス** | 正しいロケールでの応答 | 永続的 |
| **カスタムプレフィックスおよびコマンドのショートカット** | サーバーごとのコマンドのカスタマイズ | 永続的 |
| **プレミアムティアおよび有効期限** | サーバーごとのプレミアム機能の制限 | 永続的 |
| **ブラックリストのステータスと理由** | 悪用の防止 | 永続的 |

#### 1.3 モデレーションデータ
| データポイント | 目的 | 保存期間 |
|---|---|---|
| **警告** (サーバーID、ユーザーID、モデレーターID、理由) | モデレーションの監査証跡 | 永続的（ソフト削除可能） |
| **保護構成** (ホワイトリスト、閾値、罰則設定) | サーバーの荒らし防止（Anti-Raid/Anti-Spam）構成 | 永続的 |
| **イベントログのチャンネルマッピング** | 監査イベントの正しいチャンネルへのルーティング | 永続的 |

#### 1.4 機能固有のデータ
| データポイント | 目的 | 保存期間 |
|---|---|---|
| **Giveawayエントリ** (ユーザーID、参加時間) | 公平な勝者の選定 | Giveawayの削除時に削除 |
| **チケット記録** (チャンネルID、作成者ID、パネル参照、状態) | サポートチケットの追跡 | 永続的 |
| **サーバーのバックアップ** (ロール、チャンネル、権限、BAN設定) | サーバーの復元 | 手動で削除されるまで |
| **自動応答ルール** (トリガー、レスポンス) | カスタム自動返信機能 | 永続的 |
| **プレミアムコード** (コード、ティア、期間) | プレミアム機能の有効化 | 使用後に削除 |

#### 1.5 Velvra AIデータ
**Velvra AI**（プレミアム機能）をご利用の場合:
- **会話の履歴**: 各チャンネルの直近の20件のメッセージは、会話のコンテキストを維持するためにJSONファイルでローカルに保存されます。これらはデータベースには保存されず、定期的に上書きされます。
- **AIに送信されるコンテキストデータ**: サーバー名、チャンネル名、ユーザー名、ロール、権限、XP、コイン、プレミアムステータスなどがプロンプトに含まれ、パーソナライズされた応答を提供します。
- **画像添付ファイル**: AIメッセージと共に送信された画像はbase64に変換され、視覚分析のためにAIモデルに転送されます。これらは**永続的には保存されません**。
- AIのリクエストは**ローカルでホストされている**Ollamaシステムを介してルーティングされます。第三者のAIプロバイダー（OpenAIなど）にデータが送信されることはありません。

#### 1.6 収集しないデータ
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-right: 4px;"></i> メッセージの内容（プレミアム機能のAI会話を除く）
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-right: 4px;"></i> ダイレクトメッセージ (DM)
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-right: 4px;"></i> メールアドレス、IPアドレス、実名
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-right: 4px;"></i> 音声またはオーディオデータ
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-right: 4px;"></i> Discord外のブラウジングまたはアクティビティデータ

### 2. データの利用方法

当社は収集したデータを**以下の場合に限り**使用します:
- ボット機能の提供（レベリング、経済、モデレーションなど）
- エクスペリエンスのパーソナライズ
- ブラックリストの実施
- コンテキストに関連したAI応答の生成

当社は以下のようなことは**絶対に**しません:
- データを第三者に販売、共有、貸与すること
- データを広告やマーケティングの目的で使用すること
- ボットの機能以外の目的でユーザーのプロファイリングを行うこと

### 3. データストレージおよびセキュリティ

| 項目 | 詳細 |
|---|---|
| **主要なデータベース** | MongoDB (TLSによる転送の暗号化) |
| **キャッシュ層** | Redis (Upstash, `rediss://`による暗号化接続) |
| **AIのチャット履歴** | ホストサーバー上のローカルJSONファイル |
| **アクセス制限** | Creative Framework開発チームのみがデータベースへのアクセス権を持ちます |

### 4. サードパーティ・サービス

| サービス | 目的 | 共有されるデータ |
|---|---|---|
| **Discord API** | コアなボットの機能 | Discord APIが要求する範囲内 |
| **Top.gg** | ボットのリストアップと投票追跡 | ユーザーID (投票報酬のため) |
| **MongoDB Atlas** | データベースのホスティング | 上記すべての永続的なデータ |
| **Upstash Redis** | キャッシュおよびレート制限 | 一時的なセッション/クールダウンデータ |
| **Ollama（自己ホスト）** | AI応答の生成 | プロンプトテキストおよび画像データ（ローカルのみ） |

### 5. あなたの権利

あなたには以下の権利があります:
- **アクセス**: あなたに関して保存されているすべてのデータのコピーの要求。
- **削除**: あなたのユーザーデータの完全な削除の要求。
- **修正**: 不正確なデータの修正要求。
- **オプトアウト**: 特定の機能の無効化。
- **サーバーデータの削除**: サーバーからボットを削除することによる、今後のデータ収集の停止。

これらの権利を行使するには、[Creative Framework 公式Discord](https://discord.gg/qccq2mMgaT)にお問い合わせください。

### 6. お子様のプライバシー

Velvraは、13歳未満（またはお客様の地域のDiscordの利用規約で義務付けられている最低年齢）のユーザーから意図的にデータを収集することはありません。

### 7. このポリシーの変更

当社は、このプライバシーポリシーを随時更新する場合があります。重大な変更はサポートサーバーで発表されます。変更後もVelvraを継続して利用することにより、更新されたポリシーに同意したものとみなされます。
