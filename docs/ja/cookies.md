# <i class="fa-solid fa-cookie-bite" style="color: var(--velvra-primary); margin-right: 8px;"></i> クッキーポリシー

**発効日:** 2026年4月15日  
**最終更新日:** 2026年4月15日

### 1. Velvraはクッキーを使用していますか？

**いいえ。** VelvraはDiscord Botであり、ブラウザベースのクッキー追跡機能を備えた従来のウェブサイトは運営していません。ボットは完全にDiscordプラットフォーム内で動作し、ブラウザのクッキーを設定、読み取り、または管理することはありません。

### 2. 代わりに使用しているもの

クッキーは使用していませんが、運用目的のために類似のテクノロジーを使用しています：

| テクノロジー | 目的 | 詳細 |
|---|---|---|
| **Redis Cache** | クールダウンの追跡、レート制限、セッション管理 | 自動有効期限付きの一時データ（XPクールダウン、コマンドクールダウンなど）を保存します |
| **MongoDB** | 永続的なデータ保存 | ユーザーの好み、サーバー設定、およびプライバシーポリシーに記載されている機能データを保存します |
| **Local JSON Files** | AIの会話メモリ | Velvra AIのコンテキストとして、チャンネルごとに最新の20件のメッセージを保存します。定期的に上書きされます |

### 3. サードパーティによる追跡

- **Top.gg**: Top.ggでVelvraに投票した場合、同ウェブサイトは独自のクッキーポリシーに基づきクッキーを使用する場合があります。当社はWebhookを通じてあなたのDiscordユーザーIDのみを受け取ります。
- **Discord**: Discordクライアントおよびウェブサイトは、独自のクッキーおよび追跡技術を使用しています。詳細についてはDiscordのプライバシーポリシーをご参照ください。

### 4. ローカルに保存されるデータ（クッキーに類似）

以下の一時データは、クッキーと同様に機能します：

| データ | TTL (有効期間) | 目的 |
|---|---|---|
| XPクールダウンタイムスタンプ | 60秒 | XPファーミングの防止 |
| デイリー報酬クールダウン | 24時間 | 1日の請求制限 |
| 評判（Rep）クールダウン | 使用ごと | 評判スパムの防止 |
| 投票デバウンス | 30秒 | 投票報酬の重複防止 |
| コマンドクールダウン | コマンドにより異なる | レート制限 |

これらすべてのデータは、ブラウザやデバイスではなく、あなたの**Discord User ID**に紐付けられます。

### 5. お客様のコントロール

当社はブラウザのクッキーを使用しないため：
- クッキーの同意バナーやプロンプトは必要ありません。
- データの好みはボットのコマンド（通知設定など）を通じて管理されます。
- いつでもすべてのデータの削除をリクエストできます。
