# <i class="fa-solid fa-lock" style="color: var(--velvra-primary); margin-right: 8px;"></i> سياسة الخصوصية

**تاريخ السريان:** 15 أبريل 2026  
**آخر تحديث:** 15 أبريل 2026

تشرح سياسة الخصوصية هذه ما تجمعه Velvra (التي تديرها Creative Framework) من بيانات، وكيفية استخدامنا لها، وحقوقك. بإضافة Velvra إلى خادم ديسكورد الخاص بك أو التفاعل مع البوت، فإنك توافق على الممارسات الموضحة أدناه.

### 1. البيانات التي نجمعها

نقوم بجمع الحد الأدنى من البيانات اللازمة لعمل ميزات Velvra. يتم الحصول على جميع البيانات حصريًا من واجهة برمجة تطبيقات ديسكورد (Discord API) أو من تفاعلاتك المباشرة مع أوامر البوت.

| نقطة البيانات | الغرض | مدة التخزين |
|---|---|---|

| **الخبرة ومستوى التقدم** | تشغيل نظام المستوى العالمي والمهام | دائم |

| **عنوان الملف الشخصي والسمعة** | تخصيص الملف الشخصي العام | دائم |
| **الشارات** | تتبع الإنجازات المكتسبة | دائم |
| **تفضيلات الإشعارات** | احترام اختيارك لإشعارات الرسائل (DM) | دائم |
| **تقدم المهام وتتبع النشاط** | تتبع المهام اليومية (الرسائل، الأوامر، عدد الكلمات) | يُعاد التعيين يومياً، الإجماليات دائمة |

#### 1.5 بيانات الذكاء الاصطناعي (Velvra AI)
عند التفاعل مع ميزة **Velvra AI** (الميزة المدفوعة):
- **تاريخ المحادثة**: يتم تخزين آخر 20 رسالة لكل قناة محليًا في ملف JSON للحفاظ على سياق المحادثة. وهي **لا** تُحفظ في قاعدة بيانات ويتم الكتابة فوقها بشكل دوري.
- **التفاصيل المرسلة للذكاء الاصطناعي**: اسم الخادم، القناة، اسمك، الرتب الخاصة بك، والأدوار، وصلاحياتك لتوفير رد مخصص وسليم.
- **مرفقات الصور**: تُحول إلى Base64 وتُرسل للذكاء الاصطناعي لتحليل الصورة. ولا تُخزن بشكل دائم.
- **تتم معالجة الطلبات عبر خادم Ollama المستضاف محليًا**. لا توجد بيانات تُرسل لمزودي الذكاء الاصطناعي الخارجيين.

- <i class="fa-solid fa-xmark" style="color: #f87171; margin-left: 4px;"></i> الرسائل المباشرة.
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-left: 4px;"></i> عناوين IP أو كلمات المرور أو عناوين البريد الإلكتروني أو الأسماء الحقيقية.
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-left: 4px;"></i> البيانات الصوتية.
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-left: 4px;"></i> بيانات الخوادم التي لا يتواجد بها البوت.
- <i class="fa-solid fa-xmark" style="color: #f87171; margin-left: 4px;"></i> عمليات التصفح خارج ديسكورد.

### 2. كيف نستخدم بياناتك

نستخدم البيانات حصريًا لـ:
- تشغيل ميزات البوت والإشراف والاقتصاد.
- تخصيص تجربتك (اللغة وحالة الإشعارات).
- منع الإساءة وتطبيق القوائم السوداء.
- إنشاء ردود الذكاء الاصطناعي ذات الصلة.
- توفير مسارات الإشراف وحماية الخوادم للإدارات.

نحن **أبدًا** لا:
- نبيع أو نؤجر أو نشارك بياناتك مع جهات خارجية.
- نستخدم بياناتك لأغراض إعلانية أو تسويقية.
- نحلل ملفك الشخصي لأي غرض خارج وظائف البوت.

### 3. عمليات التخزين والأمان

| الميزة | التفاصيل |
|---|---|
| **قاعدة البيانات الأساسية** | MongoDB (يتم تشفيرها أثناء النقل عبر TLS) |
| **الكاش (التخزين المؤقت)** | Redis (اتصال مشفر عبر Upstash) |
| **سجل الذكاء الاصطناعي** | ملفات JSON محلية |
| **التحكم بالوصول** | حصري لفريق عمل Creative Framework فقط |
| **الاحتفاظ بالبيانات** | يُحتفظ بها طالما البوت داخل خادمك، أو حتى تطلب حذفها. |

### 4. خدمات الطرف الثالث
| الخدمة | الغرض | البيانات المشتركة |
|---|---|---|
| **Discord API** | الميزات الأساسية للبوت | كما تتطلب API ديسكورد |
| **Top.gg** | قوائم البوتات والتنصيفات | معرف المستخدم فقط (لكلمات الشكر) |
| **MongoDB Atlas** | الاستضافة السحابية | كافة البيانات الدائمة المذكورة أعلاه |
| **Upstash Redis** | الكاش | بيانات التخزين المؤقت للجلسة والكولداون (الانتظار) |
| **Ollama (محلي)** | توليد نصوص الذكاء الاصطناعي | النصوص والصور الخاصة بالمطالبة (محلياً فقط) |

### 5. حقوقك بخصوص بياناتك

أنت تمتلك كامل الحقوق في أن:
- **تصل (Access)**: طلب نسخة كاملة من جميع البيانات التي نحتفظ بها عنك.
- **تحذف (Deletion)**: طلب حذف فوري وكامل لجميع بيانات المستخدم الخاصة بك.
- **تصحح (Correction)**: طلب تصحيح أي بيانات خاطئة.
- **تنسحب (Opt-out)**: إيقاف خواص معينة (مثال: إشعارات الرسائل الخاصة).
- **إزالة بيانات الخادم**: بمجرد طرد البوت يتم إيقاف أي جمع مستقبلي للبيانات فوراً.

لتطبيق أي من تلك الحقوق قم بزيارة [خادم دعم Creative Framework](https://discord.gg/qccq2mMgaT).

### 6. خصوصية الأطفال
Velvra لا تجمع بتاتاً بيانات من المستخدمين الأقل من 13 عاماً. إذا اكتشفنا ذلك، سنحذف البيانات فوراً.

### 7. التغييرات على هذه السياسة
قد يتم تحديث سياسة الخصوصية هذه بصورة دورية، ويعد استمرار تشغيلك لخدمات البوت بمثابة موافقة ضمنية منك.
